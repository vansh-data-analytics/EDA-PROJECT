# 📊 Netflix EDA Project

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) on a Netflix dataset.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key Insights
- Most content is Movies
- Popular genre identified
- Content increased in recent years
- No strong correlation between year and duration

## 📁 Dataset
Sample Netflix dataset with 100 rows

## 🚀 Conclusion
This project helps understand content distribution and trends on Netflix.# EDA-PROJECT
